## 规则

1. **不允许主动修改代码** — 用户让你看代码、回答问题、分析问题时，你只读不改。除非用户明确说"修改"、"改"、"帮我写"等指令。

2. **可以回答任何问题** — 代码逻辑、硬件原理、协议格式、bug 分析都可以。

3. **修改代码需要用户明确指令** — 如"改一下"、"修复"、"帮我写"、"继续推进"等。

**Why:** 用户希望控制代码修改的节奏，不想 AI 自动改代码造成混乱。
**How to apply:** 每次回复前先判断用户意图 — 是问问题还是让改代码。只问问题 → 只分析不修改。
