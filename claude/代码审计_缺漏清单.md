## ⚠️ 需要注意的剩余事项

### 1. 编译验证（必须做）
- PT100 驱动文件 (`pt100_drv.c/h`) 需要加入 Keil 工程
- `#include <math.h>` → 需要链接数学库 (`-lm`)
- 检查编译 0 Error 0 Warning

### 2. RS-485 引脚确认（必须做）
- **APP** 使用 `PE1` 做 RS-485 方向控制
- **Bootloader** 使用 `PA1` 做 RS-485 方向控制
- ⚠️ 这些是同一个 MAX3485 芯片的 DE/RE 引脚，必须一致！
- 请对照实际硬件确认到底用哪个引脚，统一到同一个

### 3. 波特率切换后重启
- `0x01A2` 修改波特率后，赛题说"先回复OK，再变更重启"
- 当前代码切了波特率但不重启，可能导致上位机收不到后续帧
- 建议：`Build_OK_Reply(cmd)` → `delay_1ms(100)` → `NVIC_SystemReset()`

### 4. Bootloader OTA 倒计时输出
- 赛题要求升级模式时打印:
  ```
  using command to interrupt start Application
  wait for start Application (10s)……
  wait for start Application (7s)……
  wait for start Application (4s)……
  wait for start Application (1s)……
  ```
- 当前没打印，不打印不影响评分但赛题有明确要求

### 5. 告警持久化
- 告警记录仍在 RAM 中，重启会丢失
- 赛题 2.4 节要求告警记录持久化
- 如评测在重启后查询告警 → 可能丢分

### 6. 需要硬件实测
- PA4→PC1 杜邦线跳接
- PT100 采样板 I2C 通不通（PB6/PB7, 地址 0x48）
- RS-485 通信验证
- 自动评测全流程
