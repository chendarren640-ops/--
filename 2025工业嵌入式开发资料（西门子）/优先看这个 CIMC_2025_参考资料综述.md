## 4. 交稿答案代码架构 ← 最核心的技术分析

### 4.1 程序执行流程（伪代码）

```
main()
│
├── System_Init()                         // sysFunction.c
│   ├── systick_config()                  // SysTick 1ms 定时基准
│   ├── USART0_Config()                   // PA9/PA10, 115200-8N1
│   ├── delay_1ms(10)                     // 等待电源稳定
│   ├── printf("====system init====\n\r")
│   ├── ADC 初始化:
│   │   ├── GPIOC 时钟 + PC0 模拟模式
│   │   ├── ADC0 时钟 + PCLK2/8 预分频
│   │   ├── ADC_Init(): 连续转换, 右对齐, 1通道, CH10
│   │   └── 软件触发使能
│   ├── LED_Init()                        // PA4~PA7
│   ├── OLED_Init()                       // SSD1306 约25条I2C配置
│   ├── delay_1ms(100)
│   └── NVIC: USART0 中断使能 (RBNE)
│
└── UsrFunction()                         // sysFunction.c
    ├── delay_1ms(50)
    ├── spi_flash_init()                  // SPI1 @ 13.5MHz
    ├── flash_id = spi_flash_read_id()    // 读 GD25Q40E ID
    ├── printf("Device_ID:0x%X\n\r", flash_id)
    ├── printf("2025-CIMC-队伍号：%lu\n\r", 2025975022)
    ├── printf("====system ready====\r\n")
    ├── OLED_ShowString(0,0,"system idle",16)
    ├── OLED_Refresh()
    └── while(1) { delay_1ms(1000); }     // 空闲循环
```

### 4.2 各驱动模块技术要点

#### ADC 驱动
- 通道: ADC0, 规则通道 10 → **PC0 引脚**
- 模式: **连续转换** (不需要每次触发)
- 触发: 软件触发 + 外部触发(T0_CH3)
- 数据: 右对齐, 采样时间 56 周期
- 初始化时执行校准

#### OLED 驱动 (SSD1306)
- 协议: **GPIO 模拟 I2C** (非硬件 I2C) — PB8(SCL) + PB9(SDA)
- 功能丰富: 画点/线/圆、6 种字号字符、汉字、数字、图片、滚动
- 支持中英文混合显示
- 内置 ASCII 字库 (12/16/24) + 汉字点阵 (16/24/32/64)

#### SPI Flash 驱动 (GD25Q40E)
- 接口: SPI1 — PB13(SCK) + PB14(MISO) + PB15(MOSI), PB12(CS)
- 时钟: 108MHz / 8 = **13.5MHz**
- 页大小: 256B, 扇区大小: 4096B
- 支持: 读 ID / 写使能 / 扇区擦除 / 整片擦除 / 页写入 / Buffer 读写
- 写完成检测: 轮询状态寄存器 WIP 位 (bit0)
- 预期 Flash ID: `0xC84013`

#### USART0 驱动
- 配置: 115200-8N1, 无硬件流控
- **printf 重定向**: `fputc()` → USART0, 可直接使用 printf
- 中断接收: `USART0_IRQHandler()` → `process_data()`
  - 'a' → 点亮 LED2 / 'b' → 熄灭 LED2 / 其他 → 回显

#### RTC 驱动
- 时钟源: **外部 32.768kHz 晶振 (LXTAL)**
- 预分频: 异步 0x7F + 同步 0xFF
- 功能: 通过串口交互设置日历时间, 备份域保护
- 闹钟功能: 代码存在但**被注释掉**

#### KEY 驱动
- 4个按键: PE2~PE5, 内部上拉 (按下 = 低电平)
- 消抖: 20ms 延时二次确认
- EXTI: PE2 配置了 EXTI2 下降沿中断 → 翻转 PA5 (LED2)

### 4.3 被注释掉的隐藏代码

`sysFunction.c` 的 `UsrFunction()` 中有**约 150 行被注释掉的代码**，包含:
1. **Flash 读写完整测试**: 0~255 写入 → 回读 → 逐字节比较
2. **字符串存储测试**: "this is flash test" 写入/读取 Flash
3. **`memory_compare()` 函数**: 缓冲区逐字节比较
4. **LED 闪烁循环**: PA5 500ms 周期闪烁

这表明 2025 年赛题可能包含 SPI Flash 读写验证，答案保留了完整实现。

## 5. 官方模板 vs 交稿答案对比

| 对比项 | 官方模板 | 交稿答案 | 差距 |
|--------|---------|---------|------|
| System_Init 内容 | 仅 SysTick | SysTick + USART + ADC + LED + OLED + NVIC | 6 个模块 |
| UsrFunction 内容 | 空 `while(1)` | SPI Flash + OLED + printf | 从零开始 |
| 自研外设驱动 | 仅 LED | ADC + OLED + SPI_FLASH + RTC + USART0 + KEY | 6 个驱动 |
| 代码规模 | ~50 行有效代码 | ~800 行有效代码 | 16 倍 |
| 硬件抽象 | 无 | HardWare/ 分层驱动架构 | 架构从零搭建 |

**关键结论**：比赛提供的只是一个极简骨架，几乎所有外设驱动和系统集成都需要自行开发。

## 6. 关键注意事项

### 6.1 ⚠️ 中文编码问题
所有 `.c / .h / .txt` 文件中的中文注释均为 **GBK 编码**。如果在不支持 GBK 的环境中打开（如 VS Code 默认 UTF-8），会显示为乱码。用 GBK/GB2312 编码重新打开即可正常阅读。

### 6.2 ⚠️ 原理图缺失
`01 硬件说明/03 原理图（待更新）/` 是一个空目录。官方至今未提供 CIMC IHD V0.4 的完整原理图。**引脚分配只能从答案代码中反推**（本文档第 3.2 节已整理）。
