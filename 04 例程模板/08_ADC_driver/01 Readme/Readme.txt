# Program：CIMC_GD32_ADC_driver

## 程序简介
- 工程名称：CIMC_GD32_ADC_driver
- 实验平台: CIMC GD32F470 Development Kit V2.0
- MDK版本：5.38

## 板载资源

 - GD32F470VET6 MCU
 
 
## 功能简介

利用板载滑动变阻器改变端口电压
用ADC进行读取


## 实验操作

串口打印ADC数值

## 引脚分配

滑动变阻器 - PC0
