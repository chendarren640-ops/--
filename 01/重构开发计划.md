## 一、赛题核心约束

### 1.1 软件分层要求（赛题 2.1 节，不满足扣 20 分）
| 文件夹 | 内容 |
|--------|------|
| **Driver/** | 硬件驱动：UART、IIC、SPI、OLED、Flash、RTC 等 |
| **Protocol/** | 通讯协议：帧解析、应答组帧、CRC 校验 |
| **Function/** | 业务逻辑：采样、变比、阈值、告警、参数管理 |

### 1.2 硬件平台要求
| 参数 | 要求 |
|------|------|
| MCU | GD32F470VET6（CIMC-GD32F470 实验平台 V2.0） |
| 通信接口 | USART1 RS-485 |
| 默认波特率 | **19200**（强制！否则全部无法通信） |
| CH0 信号源 | 板载电位器 1~3V |
| CH1 信号源 | DAC 回读 PA4→PC1（需跳线短接） |
| CH2 信号源 | PT100 通过外部 ADC（GD30AD3344） |
| OLED | I2C 双行显示 |
| 外部 Flash | SPI GD25Qxx |

### 1.3 Flash 分区要求
```
Bootloader区: 0x08000000 - 0x0800FFFF (64KB)
参数区:       0x08010000 - 0x08010FFF (4KB)
App区:        0x08011000 - 0x08030FFF (128KB)
App备份区:    0x08031000 - 0x08050FFF (128KB)
固件暂存区:  0x08051000 - 0x08070FFF (128KB)
```

### 1.4 评分项（38 项，14 个模块 A~N）
| 模块 | 说明 | 分数 |
|------|------|------|
| A | 广播寻址建立通信 | ~4 |
| B | 基础查询（版本/时间/波特率/CH0/CH1/阈值） | ~15 |
| C | 时间设置 | 3 |
| D | 变比/DAC | ~12 |
| E | 阈值设置与回读 | ~4 |
| F | 重启验证持久化 | ~16 |
| G | DAC 联动（-1 扣分项） | -1 |
| H | 自动上报测试 | ~4 |
| I | 告警（开启/触发/关闭/清除） | ~11 |
| J | 睡眠后自动唤醒 | 2 |
| K | 异常帧处理（CRC/长度/非法命令/ID） | ~10 |
| L | 修改设备 ID + 重启验证 | 6 |
| M | 修改波特率 + 重启验证 | 8 |
| N | Bootloader 固件升级 | ~10+ |

## 二、一代板 vs 二代板硬件差异

### 2.1 引脚对照（基于西风example/原理图验证）
| 外设 | 一代板 (claude) | 二代板 (Development Kit V2.0) |
|------|---------------|---------------------------|
| **LED** | GPIOA PA5/PA6/PA7 | GPIOD PD8~PD13（低电平有效） |
| **RS-485 CS** | GPIOB PB12 | GPIOA PA1 |
| **USART1** | PA2/PA3 AF7 | PA2/PA3 AF7 ✅ 不变 |
| **USART0 (调试)** | PA9/PA10 | PA9/PA10 ✅ 不变 |
| **DAC** | PA4 | PA4 ✅ 不变 |
| **ADC** | ADC0 PC0(CH10)/PC1(CH11) | ADC1 PC0/PC1，VREF PC2 |
| **OLED I2C** | PB8(SCL)/PB9(SDA) | PB8/PB9 ✅ 不变 |
| **GD30AD3344** | I2C 软件模拟 | **SPI0** PA5/PA6/PA7, CS PE8 |
| **按键** | 无 | PE15/13/11/9/7, PB0, PA0 |
| **外部 Flash** | 无 | GD25Qxx SPI PB12~PB15 |
| **RTC** | LXTAL 32.768kHz | LXTAL ✅ 不变 |
| **时钟** | HXTAL 25MHz→240MHz | 同 ✅ 不变 |

### 任务 5.2：关键功能专项检查

#### 自动上报 (H-01~H-03)
- [ ] 自动上报期间**不响应普通命令**（赛题 2.1 强制要求）
- [ ] 仅响应 0x0303（停止上报）
- [x] 上报格式：UTC(4B) + CH0(4B IEEE754) + CH1(4B IEEE754) = 12B
- [ ] 上报数据是**原始采样值 × 当前变比**（赛题 2.3 节）

#### 告警系统 (I-01~I-04)
- [ ] 主动告警：超阈值后 ASCII 字符串直接回复（**非帧封装！**）
- [ ] 格式：`时间|通道|阈值|实际值\n`
- [ ] Flash 存储最近 10 次告警
- [ ] 查询返回 ASCII 字符串，无告警时回复 "empty"
- [ ] 清除后确认已清空

#### 睡眠唤醒 (J-01)
- [ ] 回复 OK 后进入深度睡眠
- [ ] RTC 闹钟 10s 后唤醒
- [ ] 唤醒后回复 "instrument wakeup"（**非帧封装！**）

#### 异常帧处理 (K-01~K-03)
- [ ] CRC 错误 → 返回 FF EEEE 错误帧
- [ ] 长度不匹配 → 返回 FF EEEE 错误帧
- [ ] 未知命令 → 返回 FF EEEE 错误帧
- [ ] ID 不匹配且非广播 → **静默丢弃，不回复**

#### 参数持久化 (F-01~F-04)
- [ ] CH0/CH1 变比重启后保持不变
- [ ] CH0/CH1 阈值重启后保持不变
- [ ] 设备 ID 重启后保持不变
- [ ] 波特率重启后保持不变

#### 修改波特率 (M-01~M-02)
- [ ] 先回复 OK，**再**切换波特率
- [ ] 11=4800, 12=9600, 13=19200, 14=115200
- [ ] 重启验证新波特率通信正常

#### Bootloader (N-01~N-03)
- [ ] APP 收到 0x0501 → 回复 OK → 写 upgrade_flag → 重启
- [ ] 正常启动：不打印任何信息，延时 5s → 跳转 APP
- [ ] 升级模式：打印倒计时 → 等待 0x0502 → 接收固件 → 校验魔术字
- [ ] 固件格式：前 4 字节魔术字 = 5A A5 C3 3C
- [ ] 切片大小：256 字节
- [ ] 魔术字不匹配 → 回复 ERROR (TT=0xFF)
- [ ] 升级后新固件不响应升级报文

### 任务 5.3：OLED 显示合规
- [ ] 第一行：队伍编号（默认 "2026263626"）
- [ ] 第二行：Bootloader 时显示 "Bootloader"

## 九、风险提示

| 风险 | 说明 |
|------|------|
| 🔴 PA4-PC1 跳线 | CH1 DAC 回读必须硬件短接 PA4→PC1 |

| 🟡 GD30AD3344 | SPI0 驱动未经实机验证 |
| 🟡 VREF 配置 | 需确认 PC2 外部参考电压或内部 VREF |
| 🟡 Bootloader 5s | 赛题要求正常模式 5s，claude 原来是 10s |
