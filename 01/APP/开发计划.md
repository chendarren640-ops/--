## Phase 2: 基础查询 (A/B/C 模块 — 19 分)

**目标**: 上位机能通过广播找到设备、查询基本信息

1. **帧解析器联调**:
   - `frame_parser.c` 中完善帧分发逻辑
   - `cmd_handler.c` 补齐所有 0x01xx 命令处理
2. **实现命令**:
   - `0x0104` 查询固件版本 → 回复 `02 00 01 00` (v2.0.1.0)
   - `0x0101` 设备重启 → OK + NVIC_SystemReset()
   - `0x0106` 查询时间 → UTC 时间戳
   - `0x0105` 设置时间 → RTC 写入
   - `0x0112` 查询波特率 → 回复 `13` (19200)
   - `0x0111` 查询设备 ID → 回复 g_param.device_id (广播 FFFF)
3. **心跳帧**: 复位后 15s 内发送心跳，ID 一致

**涉及文件**: `APP/Protocol/frame_parser.c`, `APP/Function/cmd_handler.c`, `APP/Driver/rtc_drv.c`

## Phase 3: 数据通道与持久化 (D/E/F/G 模块 — 22 分)

**目标**: ADC/DAC 采样、变比/阈值设置、重启后参数保持

1. **CH0 数据**: PC0 电位器 × 变比 → IEEE 754 浮点返回
2. **CH1 数据**: PA4 DAC 输出 → PC1 回读 × 变比
3. **变比设置**: `0x0241` (CH0), `0x0242` (CH1) — 写入 Flash 参数区
4. **阈值设置**: `0x0411` (CH0), `0x0412` (CH1) — 写入 Flash
5. **DAC 联动**: `0x0301` 设置 DAC 输出电压 → CH1 回读验证
6. **重启持久化验证**: 重启后变比、阈值、ID、波特率均保持

**硬件要求**: PA4 跳接至 PC1（DAC 输出回读）

**涉及文件**: `APP/Function/data_channel.c`, `APP/Function/cmd_handler.c`, `APP/Driver/flash_param.c`

---

## Phase 4: 自动上报与告警 (H/I 模块 — 18 分)

**目标**: 定时采集上报，超阈值告警

1. **自动上报**: `0x0302` 开始 → 按间隔 (1s/3s/5s) 发送 12 字节帧
   - UTC(4B) + CH0(4B IEEE754) + CH1(4B IEEE754)
2. **上报期间不响应其他命令** (`0x0303` 停止除外)
3. **告警**: 超阈值时字符串输出（非帧封装）
   - 格式: `时间|通道|阈值|实际值`
4. **告警查询/清除**: `0x0602` 最近 10 条, `0x0603` 清除

**涉及文件**: `APP/Function/data_channel.c`, `APP/Function/alarm_mgr.c`, `APP/Function/cmd_handler.c`

---

## Phase 5: 高级功能 (J/K/L/M 模块 — 23 分)

**目标**: 睡眠唤醒、异常处理、ID/波特率修改

1. **深度睡眠**: `0x03AA` → OK → 进入睡眠 10s → RTC 闹钟唤醒 → 回复 `instrument wakeup`
2. **异常帧处理**: CRC 错/长度错/非法命令 → 回复 `FF EEEE`
3. **修改设备 ID**: `0x01A1` → 写入 Flash → 重启生效
4. **修改波特率**: `0x01A2` → 切换 115200 → 重启仍需 115200

**涉及文件**: `APP/Function/cmd_handler.c`, `APP/Function/alarm_mgr.c`, `APP/Driver/rtc_drv.c`, `APP/Driver/flash_param.c`

---

## Phase 6: Bootloader (N 模块 — 18 分，最高分模块)

**目标**: OTA 固件升级完整流程

1. **编译 Bootloader**: 验证 `Bootloader/` 编译通过
2. **升级请求**: APP 收到 `0x0501` → OK → 写 `upgrade_flag=0xA5` → NVIC_SystemReset()
3. **Bootloader 升级模式**: 检测到 upgrade_flag → 打印倒计时 → 等待 `0x0502`
4. **固件接收**: 256 字节切片 → 校验魔术字 `5A A5 C3 3C`
5. **固件搬运**: 暂存区 (0x08051000) → APP 区 (0x08011000)
6. **拒绝错误固件**: 魔术字不匹配 → 回复错误帧
7. **验证固件不带升级功能**: 刷回 APP 后不响应升级报文

**涉及文件**: `Bootloader/main.c`, `APP/Function/cmd_handler.c`, `APP/Driver/flash_param.c`
